# CGU AIR｜CGU API 與 Codex 安裝服務圓滿完成！

**CGU AIR Team · 活動紀錄**  
**活動日期：115 年 10 月 12 日｜長庚大學**

115年10月12日，CGU AIR Team 舉辦「CGU API 與 Codex 安裝服務」活動，**共有27位師生報名參加**。為協助校內師生順利使用長庚大學提供的 AI 資源，CGU AIR Team 本次全員出動，現場協助老師與同學完成 CGU API 設定、Codex 安裝及相關環境配置，讓大家能更輕鬆地開始使用代理式 AI（Agentic AI）工具。

除了安裝服務之外，活動過程中也與許多老師、同學進行交流，討論 AI 在教學、研究、程式開發及日常工作中的應用方式，以及如何透過 Codex 提升工作效率。大家也分享了實際使用 AI 工具時遇到的問題、需求與建議，讓我們蒐集到許多寶貴的第一手回饋。這些資訊都將成為 CGU AIR 平台未來功能優化、操作流程改善及教學推廣的重要參考。

非常感謝每一位老師與同學的熱情參與！透過這次面對面的交流，我們不僅協助大家完成工具安裝，也更深入了解不同領域師生對 AI 的期待與需求。

**如果當天因為上課或其他行程無法到場，也完全不用擔心！**

CGU AIR Team 已經準備好完整的 **Step-by-step 安裝手冊**，讓大家可以依照步驟自行完成設定。此外，我們也運用長庚大學自行開發的 **AI Tutor 教學系統**，製作 Windows 與 macOS 兩種版本的詳細安裝教學影片，協助大家依照自己的電腦環境逐步操作，遇到不清楚的地方也可以反覆觀看與學習。
