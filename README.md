# CGU AIR Team 服務狀態總覽

這是一個直接讀取 Google 試算表公開 CSV 的靜態網頁，會自動排除「公開」欄位為「不公開」的項目。

直接用瀏覽器開啟 `index.html`，或使用任何靜態網站伺服器部署此資料夾。若瀏覽器限制本機檔案的跨來源請求，請以靜態伺服器啟動，例如：

```bash
npx serve .
```

頁面提供標題/系所搜尋、狀態篩選、欄位排序與重新載入功能。

「AIR Team 服務積分排行榜」彙總公開項目的「積分」欄位，同一項目的積分會完整計給每位承辦人。排行榜顯示前三個分數級距，同分者會共用一條長條並並列姓氏；滑鼠移到長條上可查看總分。
